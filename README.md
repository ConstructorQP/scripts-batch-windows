# Scripts Batch para Windows

Scripts `.bat` de la asignatura *Implantación de Sistemas Operativos* (ASIR) para automatizar tareas básicas en Windows desde la línea de comandos (CMD).

## Scripts

| Script | Qué hace |
|---|---|
| `HelloWorld.bat` | Primer script: muestra un mensaje por pantalla |
| `Nombre.bat` | Pide el nombre al usuario y lo saluda (variables y entrada con `set /p`) |
| `Fecha y hora.bat` | Muestra la fecha y la hora del sistema |
| `Crear PRUEBAS CMD.bat` | Crea carpetas y archivos en el escritorio del usuario |
| `Copiar ficheros de un sitio a otro.bat` | Copia ficheros entre una carpeta de origen y otra de destino |

## Cómo ejecutarlos

Descarga el repositorio y haz doble clic en el `.bat`, o ejecútalo desde CMD:

```cmd
cd DeberesISO
Nombre.bat
```

Revisa las rutas de origen y destino de `Copiar ficheros de un sitio a otro.bat` antes de ejecutarlo.
